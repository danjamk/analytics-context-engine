# Pre-answer checklist — <domain>

Run before returning any number. Every "no" has a stated consequence in the output.

| # | Check | Failure action |
|---|---|---|
| 1 | Grain declared and correct for the claim? | State grain; quantify any parent/child collision |
| 2 | Population applied and named? | Name who was excluded and their share |
| 3 | Right source among competing measures? | Name the rejected measure and why |
| 4 | Freshness checked and stated? | State as-of; narrow or refuse claims past it |
| 5 | Join coverage adequate for the claim? | State coverage; refuse claims that need more |
| 6 | Unmapped rows bucketed, not dropped? | Show the bucket and its share |
| 7 | Partial period flagged? | Mark PROVISIONAL; state what will change |
| 8 | Ratio denominator stated? | State it and the alternative reading |
| 9 | Total reconciles to raw source? | Report the delta; explain or refuse |
| 10 | Any caveat triggered? | State it at the number |
| 11 | Does the question match a refusal? | Refuse; offer `instead` |
| 12 | Any reading chosen that no ruling covers? | State the assumption; write a proposal |
