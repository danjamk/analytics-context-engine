# Bootstrap a context engine

The kit lives two directories above this skill's base directory (`<base>/../../`).

1. Read `<kit>/BOOTSTRAP.md` in full. It is the procedure; follow its phases in order.
2. Read `<kit>/kit/CONVENTIONS.md`, `<kit>/kit/PARTS.md`, `<kit>/kit/SCOPE.md`, `<kit>/kit/PRIVACY.md`.
3. Copy templates from `<kit>/templates/` into the operator's private locations. Never write an
   instance inside the kit directory.
4. One question at a time. Confirm each answer before writing it.
5. Before writing a first-run file, check whether `core/CORE.md` already exists. If it does, skip
   to Phase 2 of BOOTSTRAP.md.
