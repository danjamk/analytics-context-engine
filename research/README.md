# Research

A running record of the agentic-analytics market: what is changing, who is new, what shipped, and
what I think it means. It exists so this kit is built on what the industry already ships, and so
my viewpoint is based on current facts, not July's.

| File | Holds | Updated |
|---|---|---|
| `log.md` | Dated entries, newest first: releases, new players, research, ideas | As things happen; reviewed weekly |
| `landscape.md` | Which products cover which of the 25 parts, as of a date | Monthly, or when the log shows a shift |
| `numbers.md` | Benchmark figures with sources, dates, and how to cite them | When a new result lands |

## Log entry format

```markdown
### YYYY-MM-DD — <what happened, in a line>
- **What:** facts only, two or three sentences.
- **Source:** URL (and the source's own date if different).
- **Means:** my read, labeled as opinion. What it changes for the kit or for how I build.
- **Tags:** release | new-player | standard | research | idea · watch | try | write
```

Rules:

- The date is when it happened, not when I read it.
- Facts and opinion are kept apart. "Means" is the only place for opinion.
- Vendor accuracy claims are labeled vendor-reported until someone independent reproduces them.
- `try` entries get a matching trial in `lab/` when I run one.
- No client names or client details. Ever.
